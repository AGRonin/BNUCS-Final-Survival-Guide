## 复习建议
1.中国近现代史纲要

哈哈哈哈哈哈哈哈～不错不错，从这门课开始各位要开启痛苦的每学期一次的背书环节，把我一个高考考历史的半文科生都要逼疯了。但是这门课的背诵应该是最简单的吧～找好老师划重点的规律，想想如果有多个老师划出来不同重点的话你应该背哪些东西。不要太相信校圈等地得到的“复习资料”，很有可能是假的哦～然后好好背诵就行啦！

2.形势与政策1

大学生不上形策课就如同BNUCS的培养方案里失去计算机科学导论——毫无影响啊！

形策的考核方式是开卷一篇议论文，记得把开卷材料（PPT）打出来就行。

3.军事技能

23、24两届都是校内军训，比较水，卷卷就优秀了。除了对早起有点要求外……

4.通用英语进阶

跟高中英语考试差不多。另外能免修尽量快点考免修哈，除非你能保证你有每学期90+的实力（但是这很难，很多老师就是不给90+）。

5.教育学

考前把资料看一看背一背，有点印象然后凭借着实力答就行……

6.微积分I

蔡蔡子就是神！23年有选做题，24年没有，后面看看有没有吧。大部分题目比较简单，要么出现在作业之中，要么出现在上课讲的题之中（或者稍加改编）。平时基础好的直接做往年期末题，然后从题目中回头再补就行了。平时基础不好就先把留的所有作业题做好，注意要弄懂弄会，然后针对错的再去做几道类似的题，这样复习完一遍再去做期末题。反正就是只要认真复习考个不低的分时比较容易的。

7.大学物理BI

川川子的讲课真的是为数不多的人工智能学院教师中能把课上明白的了，但上课听明白不等于考试就高分了。甚至平常作业、期中、都不能划等号。23年85分已经可以排到第三了，但24年就简单许多。所以还是需要掌握的更牢固一些避免突然的难题和细节。需要掌握PPT以及课上讲的公式和题目（可能原题）。

如川川子上课时所说，如果你能刷市面上五本大学物理的习题集，你肯定能考很高的分，因为题目就那些。

8.计算机科学导论

我愿用一切最恶毒的语言形容这门课。

但貌似25年开始不是吴昊了，希望新老师能够做点正确的事情。22年听说是一篇英语文献阅读然后答题，23年是开卷4道大题（但开无可开），24年是闭卷，以下所有复习经验基于23年。看好PPT，要对大概的内容有大概的了解。这里的每一节课未来都会成为一门课甚至一个大方向，所以需要做的是有一个基本的了解。另外需要将课程的内容与实际一定的关联起来，想一想怎么应用或者在哪些方面使用之类。

无可复习，祝各位好运。

9.程序设计基础

第一门语言课程，C语言。较为基础。在熟练掌握基本语法、知识点之外，需要关注第一课中讲的一些东西（如C语言发展史等）。要有至少与平常作业相等的代码写作能力，需要注意的是手写代码没有IDE提示，可以提前联系手写代码熟悉。

## 总结
刚进入大学的你或仍然迷茫，经过这个学期，你将对大学形成初步的理解，你会打破高考后的憧憬，明白“上了大学就好了”是完全骗人的话语。你可以选择丰富多彩的社会生活，也可以选择在图书馆中度过一个个周末。大学不是象牙塔，高中与你在一间教室的不是你的对手，大学却是。你要担心来自舍友、同学的背刺，你要辩证的看待课程和老师。大学是一个小社会，你需要为自己做出决定，你需要明确自己的目标，你需要从幼稚中脱离，为了自己的未来而思考。若你想要读研，看好保研的方案/考研的科目，对着卷；若你想要出国，考虑好你的GPA和语言；若你想要就业，锻炼好你的实践水平，在实习和跟随中成长；若你想要回去继承家业，60分万岁，记得v我50～

无论以何种目标，享受你大四前课最少最少的一个学期吧～让我们回到这个仓库的初心上来，祝你顺利通过期末考试～
