## 选课建议
推荐：走近医学（数理基础课，五级课，听说再不选就不开了。如果认真听的话可以学到一些医学知识。老师很认真，但有点较真了。每节课请不同方向的专家来进行讲课。）、跨文化交流与影像实践（艺术课，需要有一定视频制作相关能力）、男子健身健美·裴嘉文、马克思主义基本原理·王晓广、李晓光（老师还不错，想听的话可以听一听，不想听划水也没问题）。

避雷：概率统计与随机过程（逆天课程安排，仅针对课程，要学的东西实在太多了课时又太短）。

## 提醒

从本学期开始，请不要对你的专业课老师抱有太大的期待。虽然看起来下一届跟我们比换了很多老师，但是……如果想要学明白学懂，自学吧！考试是考试，学习是学习。

以24-25学年的人智导为例，有一次学院的老师让我对部分课程提意见，我对人智导的评价如下：在已经经历计导（计算机科学导论，吴昊）从而不对导论课程抱有任何期待的情况下看还是不错的，总体而言成体系有结构，基本按照教材授课，自学方便。问题：部分内容跳跃，不同章节之间前后联系不强（但这个也没有太大的问题），深入理论（数学）的部分老师讲不明白（如主成分分析原理、KL变换原理、神经网络推导和原理），某章节（非实验，transformer部分）直接让助教讲（当然也没讲明白）。相对而言课程最后1/3优秀，因为都是对应方面的老师来讲课的。部分作业形式一开始时不好上手没有讲解，部分作业真正跟代码相关，但应当进行讲解，现在讲解过于简略（只是答案的说明）。部分作业意义不明确，如搜索求解_黑白棋和自主无人系统调研报告，前者完全代码，只讲解了部分抽象理论，难以完成，后者无意义。考试倾向于背诵相关定义（可以接受，但也可以探讨能否改进，我想不出来太好的方法）。

所以……能怎么办呢？

平时以搞懂真正的知识为目的自学，期末前以考试为目的复习。这是我的解法。

3.概率统计与随机过程

24貌似就换老师了。但感觉考的内容不会变化特别大？

背好概念（反正gjq喜欢考概念）。郭老师会给画重点（这重点就是把所有的念了一遍……），期末会考概念默写（我不知道24会不会考……叠甲）。

教材、教材习题、作业题（往年题、往年试卷）。

理解PPT重点基础知识，多刷题，刷不过来就多看看解题思路。马尔科夫链是重点。

简单说一下概念：样本空间、随机变量、条件概率、积事件概率、贝叶斯公式、随机变量、两个随机变量的不相关和相互独立、联合分布边缘分布条件分布的关系、协方差矩阵、依概率收敛、切比雪夫大数定律、伯努利大数定律、独立同分布中心极限定理、随机过程、宽平稳、互相关函数、正态随机过程、马尔可夫性。

可以买点练习题试试手感。

4.离散数学

PPT、教材、作业题、往年题！！！

去年考了一堆往年题/改编题。如果做过往年题的话一定要审好题（我就是在一道被改了的题里面直接填了往年的答案痛失满分）。搞清楚PPT上的知识，自己能会做作业就行。可能会有一道比较难的题，但感觉比最难的作业简单一点。

24换老师了，我真没啥话可说，懒得骂了。
